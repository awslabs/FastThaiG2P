## Format
- Enclose in forward slashes: /transcription/
- Separate syllables with a dot: /syl.la.ble/
- One word per line, format: word<TAB>/ipa/

## Consonants
Initial consonants:
  p (ป), pʰ (พ,ผ,ภ), b (บ)
  t (ต,ฏ), tʰ (ท,ถ,ฑ,ฒ,ธ), d (ด,ฎ)
  k (ก), kʰ (ข,ฃ,ค,ฅ,ฆ), ʔ (อ as initial, vowel-initial syllables)
  t͡ɕ (จ), t͡ɕʰ (ช,ฉ,ฌ)
  f (ฝ,ฟ), s (ส,ซ,ศ,ษ), h (ห,ฮ)
  m (ม), n (น,ณ), ŋ (ง)
  l (ล,ฬ), r (ร), w (ว), j (ย,ญ)

IMPORTANT: For จ always use t͡ɕ (with tie bar ͡). For ช,ฉ,ฌ always use t͡ɕʰ. NEVER use tʃ or tɕ without the tie bar.

## Final Consonants (Coda)
Thai has only 9 possible coda sounds. ALL written consonants in coda position map to one of these:

  p̚ ← บ,ป,พ,ฟ,ภ
  t̚ ← ด,ต,ถ,ท,ธ,ศ,ษ,ส,จ,ช,ซ,ฌ,ฎ,ฏ,ฑ,ฒ,ณ
  k̚ ← ก,ข,ค,ฆ
  m ← ม
  n ← น,ณ,ญ,ร,ล,ฬ
  ŋ ← ง
  j ← ย,ญ (when part of vowel)
  w ← ว (when part of vowel)
  ʔ ← glottal stop (see below)

EXCEPTION for loanwords: Foreign words that are commonly read with preserved final /s/ or /l/ keep those sounds. Examples: ปารีส /paː˧.riːs˥˩/, บาสเกตบอล → keep /s/. Use your knowledge of how Thais actually pronounce the word.

## Glottal Stop (ʔ) as Final
MANDATORY: Any syllable with a SHORT vowel and NO written final consonant ends with ʔ.
- กะปิ → /ka˨˩.piʔ˨˩/
- ผุ → /pʰuʔ˨˩/
- ขยะ → /kʰa˨˩.jaʔ˨˩/
- จะ → /t͡ɕaʔ˨˩/
- ธาตุ → /tʰaːt̚˨˩.tuʔ˨˩/

Do NOT add ʔ if vowel is long or there is a final consonant.

## Vowels
Short: a, i, u, e, ɛ, o, ɔ, ɤ, ɯ
Long: aː, iː, uː, eː, ɛː, oː, ɔː, ɤː, ɯː

Diphthongs — mark second element with ̯ (U+032F):
  ia̯ (เ-ีย), ɯa̯ (เ-ือ), ua̯ (-ัว, -วC clusters)
CRITICAL: ALWAYS write ̯ — "ua̯" not "ua", "ia̯" not "ia".

## Vowel Length — CRITICAL RULES

### Always SHORT (no ː):
- -ะ, -ั- : a
- -ิ : i
- -ุ : u
- เ-ะ : e
- แ-ะ : ɛ
- โ-ะ : o
- เ-าะ : ɔ
- เ-อะ : ɤ
- -ึ : ɯ
- เ-ือ : ɯa̯ (short diphthong)
- เ-ีย : ia̯ (short diphthong)
- -ำ : am (short a + m)
- **-อ- in CLOSED syllables** (with a final consonant): ɔ (SHORT!)
  Examples: ห้อง /hɔŋ˥˩/, ล่อง /lɔŋ˥˩/, ค่อน /kʰɔn˥˩/, ซ่อม /sɔm˥˩/, หอย /hɔj˩˩˦/, ต่อย /tɔj˨˩/
- **แ- with -็ (mai taikhu)**: ɛ (short) — แข็ง /kʰɛŋ˩˩˦/
- **แ- in closed syllable when preceded by consonant cluster**: ɛ (short) — แฮป /hɛp̚˦˥/
- **เ-ิ- (sara oe with final consonant)**: ɤ (short) — เกิด /kɤːt̚˨˩/ WAIT — actually เ-ิ- is complex:
  - เกิด = /kɤːt̚˨˩/ (LONG — this is sara oe, which IS long)
  - Correction: เ-ิ- before a single final = LONG ɤː. Only short when in เ-ิ-ะ pattern.

Let me correct: เ-ิ- (without ะ) = LONG ɤː. Example: เกิด /kɤːt̚˨˩/, เกิน /kɤːn˧/

### Always LONG (with ː):
- -า : aː
- -ี : iː
- -ู : uː
- เ- (open or before single final): eː
- แ- (without ะ or ็): ɛː
- โ- (without ะ): oː
- -อ in OPEN syllables (no final): ɔː — พ่อ /pʰɔː˥˩/, คอ /kʰɔː˧/
- เ-ิ- (sara oe, no ะ): ɤː — เกิด /kɤːt̚˨˩/
- ไ-, ใ- : aːj (long a + j)
- เ-า : aw (short a!) — เช้า /t͡ɕʰaw˦˥/, เข้า /kʰaw˥˩/

WAIT — เ-า (sara ao) = SHORT a + w. This is NOT long. เช้า = /t͡ɕʰaw˦˥/.

### Tricky cases:
- เ-า (sara ao) = /aw/ (short a + w final): เช้า /t͡ɕʰaw˦˥/, เข้า /kʰaw˥˩/, เบา /baw˧/
- -ว- as vowel in clusters = ua̯ (short): สวย /sua̯j˩˩˦/, ง่วง /ŋua̯ŋ˥˩/
- ไ-/ใ- = /aːj/: but ไม้ = /maj˦˥/ (SHORT a!) — WAIT let me check...

Actually: ไ- and ใ- vowels are phonemically /aj/ (short a + j). Some transcription systems write them as /aːj/ but Wiktionary Thai uses SHORT /aj/. Let me verify: ไป = /paj˧/, ไม่ = /maj˥˩/. Yes — Wiktionary uses SHORT a for ไ-/ใ-.

CORRECTION: ไ-/ใ- = SHORT a + j = /aj/. NOT /aːj/.

## Tones
Chao tone letters placed after the syllable:
  ˧    = mid (สามัญ)
  ˨˩   = low (เอก)
  ˥˩   = falling (โท)
  ˦˥   = high (ตรี)
  ˩˩˦  = rising (จัตวา)

Every syllable MUST have a tone mark.

## Tone Rules — CRITICAL

### Consonant Classes:
- HIGH class: ข ฃ ฉ ฐ ถ ผ ฝ ศ ษ ส ห
- MID class: ก จ ฎ ฏ ด ต บ ป อ
- LOW class: ค ฅ ฆ ง ช ซ ฌ ญ ฑ ฒ ณ ท ธ น พ ฟ ภ ม ย ร ล ว ฬ ฮ

### Dead syllables (short vowel + stop coda p̚/t̚/k̚/ʔ):
- HIGH class initial → ˨˩ (low): สัก /sak̚˨˩/, ขัด /kʰat̚˨˩/
- MID class initial → ˨˩ (low): จัด /t͡ɕat̚˨˩/, ปิด /pit̚˨˩/
- LOW class initial → ˦˥ (HIGH): นก /nok̚˦˥/, รัก /rak̚˦˥/, วัด /wat̚˦˥/, เม็ด /met̚˦˥/

THIS IS CRITICAL: Low-class + dead syllable + no tone mark = ˦˥ (HIGH tone). Claude often incorrectly assigns ˨˩ here.

### Live syllables (long vowel, or ends in sonorant m/n/ŋ/j/w):
- HIGH class, no mark → ˩˩˦ (rising): หมา /maː˩˩˦/, หลาย /laːj˩˩˦/
- MID class, no mark → ˧ (mid): กิน /kin˧/, ปลา /plaː˧/
- LOW class, no mark → ˧ (mid): ทาง /tʰaːŋ˧/, มา /maː˧/

### With tone marks:
- ่ (mai ek): HIGH/MID → ˨˩ (low), LOW → ˥˩ (falling)
- ้ (mai tho): HIGH/MID → ˥˩ (falling), LOW → ˦˥ (high)
- ๊ (mai tri): MID → ˦˥ (high)
- ๋ (mai chattawa): MID → ˩˩˦ (rising)

### อักษรนำ (Leading consonant):
When high/mid-class consonant + low-class sonorant with no vowel between:
- The sonorant behaves as HIGH class for tone.
- ถนน → /tʰa˨˩.non˩˩˦/, สนุก → /sa˨˩.nuk̚˨˩/, ขนม → /kʰa˨˩.nom˩˩˦/
- หน หม หง หญ หล หร หว → sonorant gets high-class behavior
